# Документация

Каталог `docs/` содержит справочники по программным интерфейсам
репозитория и диаграммы последовательностей KV-сервиса. Первоисточник
по коду — godoc: вывод команды `go doc github.com/vskurikhin/raft`
в корне репозитория (полный список символов пакета — `go doc -all .`).

## Справочники

Каждый справочник существует в паре: русская версия (основная) и
английский перевод с суффиксом `-en`.

| Справочник                                                                                      | Содержание                                                                                                                                                                                                                                          |
|-------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [API-ConsensusModule.md](API-ConsensusModule.md) / [English version](API-ConsensusModule-en.md) | Открытый API пакета `raft`: конструктор, роли и переходы (выборы лидера), клиентский путь (`Apply`, `VerifyLeader`), RPC, изменение состава кластера, снимки состояния, конфигурация, границы таймеров, маркерные ошибки (правило `contract.Err*`). |
| [Flags.md](Flags.md) / [English version](Flags-en.md)                                           | Флаги командной строки узла `raftkv` (21) и генератора нагрузки `loadkv` (10): умолчания, единицы, границы допустимых значений, инварианты временных параметров, профиль узла и профиль стенда.                                                     |
| [API-Data-v3.md](API-Data-v3.md) / [English version](API-Data-v3-en.md)                          | Байтовый контракт `Data`: `Apply([]byte)` и владение байтами, формат команды KVC1 (`pkg/raft/codec`), теги Data в журнале версии 3, сетевое представление AppendEntries, ошибка команды в FSM, оставшиеся gob-форматы.                                    |
